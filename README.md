# Belka PORTAL integration: hardware screenshots

Screenshots supplied by the contributor from a Samsung Android tablet running Decenza 2.0.5 with the PORTAL integration, 13 September 2026. These are real device captures, not simulated graphs.

- `live-shot.jpg`: simultaneous DE1/scale data and PORTAL raw EC/outlet temperature.
- `shot-review.jpg`: the saved shot with PORTAL curves in history.

These captures precede the PR's layout correction: the live readout and view selector still overlap the header/axis in this test build. The correction is tested in the PR source; verification of the corrected layout on the tablet is pending. Shot Review was captured with its upper content partially behind the status bar.

EC units and compensation are unverified. The PORTAL display curve was confirmed separately by the owner; these images do not establish persistent device-side sessions.
